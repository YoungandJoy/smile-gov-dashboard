## 🚀 GitHub Pages 배포 방법

### 방법 1: GitHub 웹에서 직접 (가장 쉬움)

1. [GitHub.com](https://github.com) 로그인
2. **New repository** 클릭
3. Repository name: `smile-gov-dashboard`
4. **Public** 선택
5. **Create repository**
6. `index.html`, `README.md` 파일 업로드
7. **Settings** → **Pages** → Source: `main` 브랜치 선택 → **Save**
8. 약 1~2분 후 `https://[username].github.io/smile-gov-dashboard/` 접속

### 방법 2: Git 명령어

```bash
git init
git add .
git commit -m "Add SMILE 2026 정부지원사업 대시보드"
git remote add origin https://github.com/[YOUR-USERNAME]/smile-gov-dashboard.git
git push -u origin main
```
그 후 GitHub → Settings → Pages → Source: main 설정
